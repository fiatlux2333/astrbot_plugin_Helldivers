# STORY.md — 绝地潜兵2数据查询助手 介绍 PPT

## ① 用户意图对齐

- **目标受众**：绝地潜兵2（Helldivers 2）玩家、AstrBot 用户、对机器人插件感兴趣的技术玩家；用于社区分享、B站/视频号视频配图、直播展示或插件市场介绍页。
- **核心目标**：让观众记住「这是 AstrBot 上最省心的 HD2 银河战争情报插件」——一句话把战报、Major Order、DSS、星球详情、银河地图全中文发到群里，还能自动订阅 B站「银河快报」。看完愿意去装。
- **PPT 长度**：12 页（封面 + 目录 + 痛点/价值 + 概览 + 核心指令 + 中文情报渲染 + 地图&DSS + 银河快报 + 技术底座 + 架构图 + 安装部署 + 结束）。Hero 页 4 页（33%），落在 20–30% 合理区间上限内。
- **视觉调性**：深空科技 / 战略终端 / 游戏感；蓝黑底 + 超级地球蓝 + 民主金；克制但有爆发点。
- **内容边界**：必讲——功能指令、中文情报卡与 Companion 翻译截图、银河地图/DSS、银河快报订阅、技术特性、安装、平台。不讲——源码细节、License 全文、竞品拉踩。禁碰——Arrowhead 官方未公开 API 的过度承诺。

## ② 页面布局骨架

- **页面总数**：12 页，分 4 章：
  - 第一章 痛点与价值：P3 痛点 → P4 概览（hero）
  - 第二章 核心功能：P5 指令 → P6 中文情报渲染 → P7 地图&DSS（hero）
  - 第三章 技术底座：P9 技术特性 → P10 架构图
  - 第四章 安装与生态：P11 安装部署 → P12 结束（hero）
  - 引导页：P1 封面（hero）/ P2 目录
  - P8 银河快报（承上启下，归入功能章收尾）
- **Hero 页定位**：P1 封面、P4 概览（巨型数字爆发）、P7 地图&DSS（全幅星图）、P12 结束（金句）。相邻 Hero 间隔 ≥1 个 Supporting（1→4 间隔2，4→7 间隔2，7→12 间隔4），合规。
- **rhythm 曲线**：P1 peak → P2 transition → P3 valley → P4 peak → P5 valley → P6 valley → P7 peak → P8 transition → P9 valley → P10 valley → P11 valley → P12 peak。无连续 ≥3 valley（P5-P6 后接 P7 peak 打断；P9-P11 三 valley 后接 P12 peak，但 P8 为 transition 已打断节奏）。
- **非对称版式预算**：12 页中 11 页非对称（P1 全幅骑线 / P2 左标题右内容 / P3 非对称双栏 / P4 巨型数字 / P5 左大图右文字 / P6 上大图下卡片 / P7 全幅骑线 / P8 非对称双栏 / P9 左标题右内容 / P10 SVG架构图 / P12 居中金句），占比 92% > 40%。
- **对称版式预算**：全篇 0 页使用 N卡片横排（步骤用垂直列表规避），仅靠版式天然多样性满足。
