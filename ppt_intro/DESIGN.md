# DESIGN.md — 绝地潜兵2数据查询助手 介绍 PPT（深空科技风）

## 1. 画布与全局母版（A/B/C 三区）

- 画布：1280×720，16:9；padding 上下 20、左右 64。
- **A 标题块** 0–120px：主标题 34px bold（深色页用浅色字）；封面/章节/结束页可自定义。
- **B 内容区** 120–660px：正文、图、卡、架构图。
- **C 页脚条** 660–720px：左侧「HD2 · 绝地潜兵2数据查询助手」水印（14px 灰蓝），右侧页码 `NN / 12`（14px 灰蓝）。
- 封面/结束页省略 C 区，使用自定义版式。
- 全篇母版骨架、标题位置、页码位置严格一致。

## 2. 颜色系统（≤4 彩色 hex + 中性文本）

| 角色 | hex | 用途 |
|------|-----|------|
| 背景深空 | `#0B1424` | 全篇底色、大色块 |
| 主色（模块蓝） | `#16335C` | 标题栏底色、卡片底、区块 |
| 强调·超级地球蓝 | `#3D9BE9` | 焦点元素、图标、链接、CTA |
| 强调·民主金 | `#F5A623` | Hero 数字、关键高亮、口号（仅 Hero/焦点） |
| 文本主色 | `#EAF1FB` | 正文/标题（浅色页） |
| 文本次色 | `#8FA3BF` | 副文、页脚、注释 |
| 阵营点缀 | `#5BA85B`(终结族) / `#D64545`(机器人) / `#9B6BD6`(光能族) | 仅地图/三阵营标注 |

**色彩面积分配**：背景深空 ≤60%；模块蓝 ≤30%；超级地球蓝 ≤10%（焦点）；民主金 ≤10%（仅 Hero/CTA）。Supporting 页强调色≤5%。
**渐变**：`linear-gradient(135deg, #16335C 0%, #0B1424 100%)` 用于标题栏/卡片头；背景叠 `rgba(61,155,233,0.10)` 浅蓝蒙版；封面/地图页背景叠深空星图 SVG + `rgba(11,20,36,0.55)` 蒙版保证白字可读。

## 3. 字体系统

- 标题：`'Microsoft YaHei'`（微软雅黑），bold；封面主标题 64px，章节大字 60px，页面主标题 34px。
- 正文：`'Microsoft YaHei'`，regular，22–24px，lineHeight 1.5。
- 命令/代码：等宽 `'Consolas'`，20–22px，民主金或超级地球蓝，表现终端感。
- 巨型锚点数字：`'Microsoft YaHei'` bold 72–110px，民主金 `#F5A623`（仅 Hero）。
- 禁止全篇只用默认无衬线；标题与正文允许同字体但靠字重/字号拉开层级。

## 4. 信息密度门禁

- 常规内容页：标题+正文+主视觉，正文≥180字（含卡内），留白≤35%。
- 卡片组：每卡≥100字合计，填充率≥85%，尾部元素用 `marginTop:auto` 钉底。
- 焦点留白：每个锚点元素周围≥40px 呼吸空间；Hero 留白可达40%。
- 禁止均匀稀薄留白。

## 5. 配图系统

- **L1 主视觉**：封面深空星图、P5 终端窗口、P6 中英对照卡、P7 银河星图、P10 架构图——全部用 `<SVG>` 绘制（抽象几何/星图/终端/架构，非具象场景，符合 SVG 白名单：背景网格、星图、架构图、巨型数字、终端窗口概念）。不使用 ImageGen（避免版权风险与耗时，且本主题为抽象科技视觉，SVG 足以胜任）。
- **L2 支撑图**：P3 警告图标、`P8` 动态卡、`P11` 步骤块——用 FAIcon + 色块容器。
- **L3 角标**：全篇统一星徽（SVG 小星/盾）置于页脚左或标题左，位置固定。
- 严禁 200×70 装饰小贴片塞标题栏；正文页不用全屏背景图（星图仅用于封面/地图 hero 页）。
