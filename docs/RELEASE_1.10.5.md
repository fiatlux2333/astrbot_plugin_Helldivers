# v1.10.4 / v1.10.5 两批交付说明

日期：2026-11-07。本文件记录本地 v1.10.4 / v1.10.5 两批交付，当前版本已更新至 [v2.0.0](RELEASE_2.0.0.md)。

**兼容性更正：** 此前“可从旧版本直接升级并保留待补发队列”的说明范围过宽。本地开发基于 `dd5e67c`，没有合入远端 main 的 `cdcd162`（同样标记 v1.10.3）及其后的 `codex`。这些远端版本使用 `pending` / `queued_at`，本地使用 `pending_posts` / `pending_news`，尚无迁移。保留数据目录本身不能保证跨开发线的待补发记录继续生效；不可用本文件作为 codex 无损升级说明。

v1.10.5 包含本地两批改动和此前本地推送修复；v1.10.4 为第一批的独立包。

## 第一批：v1.10.4

- 装备补充目录按集合保留最后成功数据。部分上游失败、缓存过期或主目录不可达时，有效缓存仍可用于查询。
- UApi builtin 区分接口限流、额度耗尽与网络错误；暂停重复请求，保留原文。增加管理员 `/hd2翻译恢复`。
- Companion 按ID新闻改用战争计时换算日期；关键时间无效时显示未知，避免产生错误日期。
- DSS仅使用现行v2接口；失败时保留最后成功数据，文本标注缓存时间。
- 包含按群持久化补发及OneBot退群订阅清理修复。

第一批完整测试：183项通过，51个子用例通过。

## 第二批：v1.10.5

- HD2Tool中文名及俗称与dionatha数据按“类别 + 稳定标识”合并，同名护甲/头盔可明确选择。
- 数值区分基础/升级条件；保留零值、显式未知、热量武器机制、多档射速、弹丸数量和有明确依据的持续伤害单位。
- 卡片注明数据来源版本和上游质量标记；老缓存显示最后成功获取时间。
- 新增管理员 `/hd2data刷新`，并发调用合并；`/hd2ping` 展示各集合的版本、数量、时间和失败状态。
- 补充被动表依赖校验、写缓存中断处理、过期缓存重启恢复；DSS本地图片也标注数据时间。

以2026-11-07抓取的样本验证：主目录298项、补充目录601项，共296对按类别匹配成功，生成603条装备记录；敌人86项。两条未找到可靠对应标识的主目录记录独立保留，不按模糊名字强行合并。

## 安装与验收

1. 备份当前插件目录及 AstrBot 的 `plugin_data/astrbot_plugin_Helldivers` 数据目录。若部署有自定义数据路径，以实际配置为准。
2. 在 AstrBot WebUI 使用 v1.10.5 ZIP 更新插件并重载。**保留插件数据目录**；装备和成功翻译缓存沿用；待重试队列只保证本地兼容格式继续使用，远端 main/codex 格式需要先迁移。
3. 执行 `/hd2ping`，确认显示 v1.10.5；执行 `/hd2data刷新` 后再查看各集合状态。部分失败时会明确显示并继续保留旧数据。
4. 检查以下命令：

```text
/hd2data 40-K
/hd2data 飞鹰空袭
/hd2data LAS-16
/hd2data A-35 Recon
/hd2data A-35 Recon 头盔
/hd2data AR-23L Liberator Legacy
/hd2data Noxious Spewer
/dss
/hd2订阅列表
```

熔枪应分别展示基础480秒和全升级410.4秒；镰刀应显示热量机制；A-35应可区分护甲和头盔。上述数值是本次验收快照，未来随上游更新可能变化。

管理员确认翻译额度恢复后可执行 `/hd2翻译恢复`，该操作只解除暂停。`/hd2refresh` 仍用于Companion截图，装备刷新使用 `/hd2data刷新`。

若需回滚，停止/卸载插件后恢复备份的代码和对应数据目录；不要在运行时用旧数据覆盖正在更新的状态文件。v1.10.4可作为不含装备合并逻辑的版本使用。

最终完整测试：195项通过，53个子用例通过。两条警告来自现有第三方依赖的弃用提示。
