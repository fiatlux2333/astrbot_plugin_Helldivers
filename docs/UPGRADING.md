# 升级与数据

返回 [使用说明](../README.md)。

## 更新插件

1. 备份插件代码和数据目录，默认数据位置为 `data/plugin_data/astrbot_plugin_Helldivers/`；自定义部署以实际配置为准。
2. 在 AstrBot 中停止插件，完成更新后重新加载。保留原数据目录。
3. 执行 `/hd2ping`、`/hd2订阅列表` 检查状态，再测试常用命令。

## 订阅与待补发记录

已识别的旧队列会自动迁移。迁移前在对应推送目录保存 `state.before-v3.<摘要>.json`；Companion 的旧 `pending_*.png` 截图也会保留，活动待补发截图放在 `outbox/`。

从 `v2.0.0` 更新时，订阅及待补发记录沿用原格式，无需清空数据。

迁移保留尚未成功的接收群，成功群不会因重启重新加入队列。已有记录仍受 [保留策略](CONFIGURATION.md#待补发保留策略) 约束：超过期限或容量会清理并停止补发。备份与旧截图不计入活动队列容量，确认运行正常后可自行归档。

首次切换新闻去重方式时，只为当前内容建立基线；已有待补发记录继续重试。

## 状态保护与回滚

无法识别的状态、损坏记录或缺失的旧截图，会使对应推送通道暂停并保留原文件。通过 `/hd2订阅列表` 和日志查看原因，修复文件或恢复备份后再重载。已经被旧程序覆盖的记录，需要从覆盖前的备份恢复。

需要回滚时，先停止插件，再恢复相互匹配的旧代码、状态文件和截图。不要在运行中覆盖状态，也不要让旧代码直接读取迁移后的新格式。
